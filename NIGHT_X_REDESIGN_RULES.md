# Night X Redesign Rules

1. **Always inspect current code before editing.**
2. **Do not break existing tool functionality.**
3. **Reuse shared components where possible.**
4. **Improve design system first, then pages.**
5. **Do not add unnecessary text or fake features.**
6. **Do not leave broken links, placeholder icons, console errors, or TypeScript errors.**
7. **Every phase must end with tests/build/lint where possible.**
8. **After every phase, reread `NIGHT_X_REDESIGN_RULES.md` and say: "Ready for next phase."**
9. **Keep changes professional, minimal where needed, and scalable.**
10. **If a feature is incomplete, clearly mark it as disabled, coming soon, or remove public links to it.**
